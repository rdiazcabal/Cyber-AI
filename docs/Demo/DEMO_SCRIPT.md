# 2inc-cyberpro - Demo Script

## Objetivo de la demo

Mostrar cómo 2inc-cyberpro ayuda a una empresa a detectar, analizar, documentar y dar seguimiento a posibles incidentes de ciberseguridad usando inteligencia artificial.

Duración recomendada: 10 a 15 minutos.

---

## 1. Introducción

2inc-cyberpro es una plataforma de seguridad con inteligencia artificial que ayuda a empresas a entender incidentes de seguridad, generar reportes, crear casos de investigación, buscar amenazas históricas y tener evidencia para auditoría.

No reemplaza un SOC enterprise, pero permite a empresas medianas tener visibilidad y control sin una inversión compleja.

---

## 2. Mostrar Dashboard principal

Mensaje para el cliente:

"Este es el tablero principal. Aquí podemos analizar eventos o logs de seguridad y obtener un resumen de riesgo, hallazgos, indicadores de compromiso y recomendaciones."

Acción:
- Ir a Dashboard.
- Mostrar el área para pegar eventos.
- Explicar que también se pueden subir archivos `.json`, `.txt` o `.log`.

---

## 3. Ejecutar análisis de prueba

Acción:
- Pegar un sample log.
- Presionar Analyze.

Mensaje:

"Ahora la plataforma procesa los eventos, identifica patrones sospechosos, calcula un riesgo, extrae indicadores y genera una interpretación entendible."

---

## 4. Mostrar resultados

Explicar:

- Risk Score
- Timeline
- Incident Summary
- Detection Feed
- MITRE Coverage
- Indicators of Compromise
- Threat Intelligence
- ML Anomaly Detection

Mensaje:

## 7. Mostrar Case Management

Acción:
- Ir a Case Management.
- Abrir un caso.
- Cambiar estado.
- Agregar nota.

Mensaje:

"Cuando se detecta algo importante, se crea un caso de investigación. El equipo puede asignarlo, actualizar el estado y documentar el seguimiento."

Estados sugeridos:
- open
- investigating
- contained
- resolved
- false_positive

## 8. Mostrar Threat Hunting

Acción:
- Buscar una IP, dominio o usuario.

Ejemplo:
- 8.8.8.8
- admin-user
- malicious-example.com

Mensaje:

"Threat Hunting permite buscar si una IP, dominio, usuario o recurso ya apareció antes. Esto ayuda a conectar incidentes relacionados."

---

## 9. Mostrar CIS 8 Compliance

Acción:
- Ir a CIS 8 Compliance.
- Expandir un control.
- Mostrar findings asociados.
- Descargar CIS Evidence PDF.

Mensaje:

"La plataforma ayuda a mapear hallazgos contra CIS Controls v8 y generar evidencia para auditoría o revisiones internas."

Importante:
No decir que la empresa queda certificada.
Decir que ayuda a preparar evidencia y mejorar cumplimiento.
