# Preguntas de descubrimiento para prospectos

## Situación actual

1. ¿Actualmente tienen equipo de ciberseguridad interno?
2. ¿Quién revisa los eventos o logs de seguridad?
3. ¿Tienen algún SIEM, SOC o herramienta de monitoreo?
4. ¿Usan AWS, Azure, GCP o servidores propios?
5. ¿Han tenido incidentes de seguridad recientemente?

## Dolor del cliente

6. Cuando ocurre algo sospechoso, ¿cómo determinan si fue grave?
7. ¿Cuánto tiempo tardan en generar un reporte de incidente?
8. ¿Tienen evidencia documentada para auditorías?
9. ¿Pueden saber si una IP o usuario sospechoso ya apareció antes?
10. ¿Quién da seguimiento a los incidentes hasta cerrarlos?

## Cumplimiento

11. ¿Tienen auditorías SOC 2, ISO 27001, PCI, HIPAA, GDPR o similares?
12. ¿Les piden evidencia de controles de seguridad?
13. ¿Tienen políticas de retención de logs o reportes?
14. ¿Necesitan reportes ejecutivos para gerencia?

## Valor

15. ¿Les ayudaría reducir el tiempo de análisis de incidentes?
16. ¿Les serviría tener reportes PDF automáticos?
17. ¿Les interesa tener un dashboard ejecutivo de riesgos?
18. ¿Les gustaría iniciar capacidades SOC sin una plataforma enterprise costosa?

## Cierre

19. ¿Podemos hacer un piloto con logs anonimizados?
20. ¿Qué resultado haría que consideren exitoso el piloto?
