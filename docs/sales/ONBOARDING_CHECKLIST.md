# Onboarding Checklist

## 1. Información del cliente

- Nombre de empresa
- Contacto principal
- Contacto técnico
- Industria
- Número aproximado de usuarios
- Sistemas críticos
- Nube utilizada: AWS / Azure / GCP / On-premise

## 2. Alcance inicial

- Qué sistemas se analizarán
- Qué tipo de logs se usarán
- Frecuencia de análisis
- Usuarios que tendrán acceso
- Roles requeridos

## 3. Configuración inicial

- Crear empresa en 2inc-cyberpro
- Crear usuario company_admin
- Crear usuarios analistas
- Configurar retención
- Configurar exportación PDF
- Configurar alertas si aplica

## 4. Datos de prueba

- Cargar logs de ejemplo
- Ejecutar primer análisis
- Revisar reporte
- Crear o validar casos
- Revisar CIS 8 mapping
- Revisar Audit Logs

## 5. Validación con cliente

- Confirmar que entiende el dashboard
- Confirmar que puede descargar reportes
- Confirmar que puede buscar IOCs
- Confirmar que puede revisar casos
- Confirmar que puede usar el dashboard ejecutivo

## 6. Entregables iniciales

- Primer reporte PDF
- Recomendaciones iniciales
- Usuarios configurados
- Política de retención definida
- Sesión de capacitación realizada

## 7. Próximos pasos

- Definir periodicidad de revisión
- Definir responsable interno
- Definir canal de comunicación
- Definir métricas mensuales
